# История изменений - Trest Language

## Версия 2.0.0 (Текущая)

### Основные изменения

- ✅ **Полная поддержка кириллицы** - Все ключевые слова только на русском языке
- ✅ **Удалены слова на португальском** - Язык теперь полностью на кириллице
- ✅ **Расширенная документация** - Полная документация в папке `docs/`
- ✅ **Новые типы токенов** - Добавлена поддержка switch, case, do-while, async/await
- ✅ **Расширенная стандартная библиотека** - Больше функций в std

### Новые функции

- Поддержка `switch/case`
- Поддержка `do-while`
- Поддержка классов с наследованием
- Расширенная обработка ошибок
- Улучшенная система модулей

### Документация

- Создана полная документация в `docs/`
- Добавлены примеры кода
- Добавлены лучшие практики
- Добавлен API Reference
