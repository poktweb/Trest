## Начало работы

### Ваша первая программа

Создайте файл `привет.trest`:

```trest
печать("Привет, Мир!")
```

Запустите:

```bash
trest привет.trest
```

Вывод:
```
Привет, Мир!
```

## Основы синтаксиса

### Переменные

```trest
# Объявление переменной
пусть имя = "Иван"
пусть возраст = 25

# Изменение значения
возраст = 26

# Константа
конст PI = 3.14159
```

### Типы данных

```trest
# Числа
пусть число = 42
пусть дробное = 3.14

# Строки
пусть текст = "Привет"

# Логические
пусть правда = истина
пусть ложное = ложь

# Массивы
пусть список = [1, 2, 3]

# Объекты
пусть человек = {
    имя: "Иван",
    возраст: 30
}
```

## Работа с данными

### Массивы

```trest
пусть числа = [1, 2, 3, 4, 5]

# Доступ к элементам
печать(числа[0])  # 1

# Изменение
числа[0] = 10
печать(числа)  # [10, 2, 3, 4, 5]

# Итерация
для (пусть число из числа) {
    печать(число)
}
```

### Объекты

```trest
пусть человек = {
    имя: "Иван",
    возраст: 30,
    город: "Москва"
}

# Доступ к свойствам
печать(человек.имя)           # "Иван"
печать(человек["возраст"])    # 30

# Изменение
человек.возраст = 31

# Добавление свойства
человек.страна = "Россия"
```

## Функции и модули

### Создание функций

```trest
функция приветствие(имя) {
    вернуть "Привет, " + имя
}

печать(приветствие("Иван"))  # "Привет, Иван"
```

### Модули

**math.trest:**
```trest
экспорт функция сложить(a, b) {
    вернуть a + b
}

экспорт функция умножить(a, b) {
    вернуть a * b
}
```

**main.trest:**
```trest
импорт { сложить, умножить } из "./math.trest"

печать(сложить(5, 3))    # 8
печать(умножить(2, 4))   # 8
```

## Объектно-ориентированное программирование

### Классы

```trest
класс Человек {
    функция конструктор(имя, возраст) {
        это.имя = имя
        это.возраст = возраст
    }
    
    функция представиться() {
        печать("Я " + это.имя + ", мне " + это.возраст + " лет")
    }
}

пусть иван = новый Человек("Иван", 30)
иван.представиться()  # "Я Иван, мне 30 лет"
```

### Наследование

```trest
класс Студент расширяет Человек {
    функция конструктор(имя, возраст, группа) {
        супер(имя, возраст)
        это.группа = группа
    }
    
    функция учиться() {
        печать(это.имя + " учится")
    }
}

пусть студент = новый Студент("Мария", 20, "ИТ-101")
студент.представиться()  # "Я Мария, мне 20 лет"
студент.учиться()        # "Мария учится"
```

## Работа с ошибками

### try/catch

```trest
попытаться {
    пусть результат = 10 / 0
} перехватить (ошибка) {
    печать("Произошла ошибка: " + ошибка)
}
```

### Создание ошибок

```trest
функция делить(a, b) {
    если (b == 0) {
        бросить "Деление на ноль невозможно!"
    }
    вернуть a / b
}

попытаться {
    делить(10, 0)
} перехватить (ошибка) {
    печать("Ошибка: " + ошибка)
}
```

## Советы и практики

### Именование

- Используйте понятные имена: `имя`, `возраст`, `счетчик`
- Избегайте сокращений: `им` вместо `имя` - плохо
- Используйте camelCase для переменных: `имяПользователя`

### Организация кода

- Разделяйте логику на функции
- Используйте модули для организации больших проектов
- Комментируйте сложные участки кода

### Обработка ошибок

- Всегда обрабатывайте возможные ошибки
- Используйте try/catch для критических операций
- Предоставляйте понятные сообщения об ошибках
