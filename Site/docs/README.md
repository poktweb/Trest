## Введение

**Trest** - это современный язык программирования, написанный на TypeScript/Node.js, с полной поддержкой кириллицы (русского алфавита). Язык компилируется для Web (JavaScript) и Desktop (.exe).

### Основные характеристики

- ✅ **Синтаксис на кириллице** - Все ключевые слова на русском языке
- ✅ **Динамическая типизация** - Типы выводятся автоматически
- ✅ **Компиляция для Web и Desktop** - Генерирует JavaScript и исполняемые файлы
- ✅ **Система модулей** - Импорт/экспорт модулей
- ✅ **Стандартная библиотека** - Богатый набор функций
- ✅ **Обработка ошибок** - Полный try/catch/throw

## Типы данных

### Базовые типы

Trest поддерживает следующие типы данных:

#### 1. Числа (Number)

```trest
пусть целое = 42
пусть дробное = 3.14159
пусть отрицательное = -10
```

#### 2. Строки (String)

```trest
пусть строка1 = "Двойные кавычки"
пусть строка2 = 'Одинарные кавычки'
пусть многострочная = """
Первая строка
Вторая строка
Третья строка
"""
```

#### 3. Логические (Boolean)

```trest
пусть истина = истина
пусть ложь = ложь
```

#### 4. Null и Undefined

```trest
пусть пусто = нуль
пусть неопределено = неопределен
```

#### 5. Массивы (Array)

```trest
пусть числа = [1, 2, 3, 4, 5]
пусть смешанный = [1, "два", истина, 4.5]
пусть пустой = []
```

#### 6. Объекты (Object)

```trest
пусть человек = {
    имя: "Иван",
    возраст: 30,
    город: "Москва"
}

печать(человек.имя)  # "Иван"
печать(человек["возраст"])  # 30
```

## Переменные

### Объявление переменных

Trest поддерживает три способа объявления переменных:

#### 1. `пусть` (let) - Блочная область видимости

```trest
пусть x = 10

если (истина) {
    пусть y = 20  # Доступна только внутри блока
    печать(y)  # 20
}

печать(x)  # 10
# печать(y)  # Ошибка! y недоступна здесь
```

#### 2. `конст` (const) - Константа

```trest
конст PI = 3.14159
конст ИМЯ = "Trest"

# PI = 3.14  # Ошибка! Нельзя переприсваивать
```

#### 3. `перем` (var) - Функциональная область видимости

```trest
перем глобальная = 100

функция тест() {
    перем локальная = 200
    печать(глобальная)  # 100
    печать(локальная)   # 200
}
```

### Присваивание

```trest
пусть x = 10
x = 20  # Новое значение

# Множественное присваивание
пусть a = 1
пусть b = 2
a, b = b, a  # Обмен значений
```

## Операторы

### Арифметические операторы

```trest
пусть a = 10
пусть b = 3

печать(a + b)   # 13 - Сложение
печать(a - b)   # 7  - Вычитание
печать(a * b)   # 30 - Умножение
печать(a / b)   # 3.333... - Деление
печать(a % b)   # 1  - Остаток от деления
печать(a ** b)  # 1000 - Возведение в степень
```

### Операторы сравнения

```trest
пусть x = 10
пусть y = 20

x == y   # false - Равно
x != y   # true  - Не равно
x < y    # true  - Меньше
x > y    # false - Больше
x <= y   # true  - Меньше или равно
x >= y   # false - Больше или равно
```

### Логические операторы

```trest
пусть a = истина
пусть b = ложь

a && b   # false - И (AND)
a || b   # true  - ИЛИ (OR)
!a       # false - НЕ (NOT)
```

### Операторы присваивания

```trest
пусть x = 10

x += 5   # x = x + 5 → 15
x -= 3   # x = x - 3 → 12
x *= 2   # x = x * 2 → 24
x /= 4   # x = x / 4 → 6
x %= 5   # x = x % 5 → 1
```

### Оператор nullish coalescing (??)

```trest
пусть x = нуль ?? 10  # x = 10 (если null/undefined, то 10)
пусть y = 0 ?? 20     # y = 0 (0 не null, остается 0)
```

### Оператор optional chaining (?.)

```trest
пусть объект = { a: { b: 10 } }
печать(объект.a?.b)        # 10
печать(объект.x?.y)        # undefined (без ошибки)
```

## Структуры управления

### Условные операторы

#### if/else

```trest
пусть возраст = 20

если (возраст >= 18) {
    печать("Совершеннолетний")
} иначе {
    печать("Несовершеннолетний")
}

# Цепочка if-else
если (оценка >= 90) {
    печать("Отлично")
} иначе если (оценка >= 70) {
    печать("Хорошо")
} иначе если (оценка >= 50) {
    печать("Удовлетворительно")
} иначе {
    печать("Неудовлетворительно")
}
```

#### switch/case

```trest
пусть день = 3

переключатель (день) {
    случай 1:
        печать("Понедельник")
        прервать
    случай 2:
        печать("Вторник")
        прервать
    случай 3:
        печать("Среда")
        прервать
    поумолчанию:
        печать("Другой день")
}
```

### Циклы

#### while

```trest
пусть i = 0
пока (i < 5) {
    печать(i)
    i = i + 1
}
```

#### do-while

```trest
пусть i = 0
делать {
    печать(i)
    i = i + 1
} пока (i < 5)
```

#### for

```trest
# Классический for
для (пусть i = 0; i < 5; i = i + 1) {
    печать(i)
}

# for-in (по ключам объекта)
пусть объект = { a: 1, b: 2, c: 3 }
для (пусть ключ в объект) {
    печать(ключ + ": " + объект[ключ])
}

# for-of (по элементам массива)
пусть массив = [10, 20, 30]
для (пусть элемент из массив) {
    печать(элемент)
}
```

#### break и continue

```trest
# break - прерывает цикл
для (пусть i = 0; i < 10; i = i + 1) {
    если (i == 5) {
        прервать  # Выход из цикла
    }
    печать(i)
}

# continue - пропускает итерацию
для (пусть i = 0; i < 10; i = i + 1) {
    если (i % 2 == 0) {
        продолжить  # Пропустить четные числа
    }
    печать(i)  # Печатает только нечетные
}
```

## Функции

### Объявление функций

```trest
функция приветствие(имя) {
    вернуть "Привет, " + имя + "!"
}

печать(приветствие("Иван"))  # "Привет, Иван!"
```

### Параметры по умолчанию

```trest
функция приветствие(имя = "Гость") {
    вернуть "Привет, " + имя + "!"
}

печать(приветствие())      # "Привет, Гость!"
печать(приветствие("Иван")) # "Привет, Иван!"
```

### Rest параметры

```trest
функция сумма(...числа) {
    пусть результат = 0
    для (пусть число из числа) {
        результат = результат + число
    }
    вернуть результат
}

печать(сумма(1, 2, 3, 4, 5))  # 15
```

### Функции высшего порядка

```trest
функция применить(f, x) {
    вернуть f(x)
}

функция удвоить(n) {
    вернуть n * 2
}

печать(применить(удвоить, 5))  # 10
```

### Замыкания (Closures)

```trest
функция создатьСчетчик() {
    пусть счет = 0
    функция увеличить() {
        счет = счет + 1
        вернуть счет
    }
    вернуть увеличить
}

пусть счетчик = создатьСчетчик()
печать(счетчик())  # 1
печать(счетчик())  # 2
печать(счетчик())  # 3
```

### Стрелочные функции (Lambda)

```trest
пусть удвоить = (x) => x * 2
пусть сложить = (a, b) => a + b

печать(удвоить(5))     # 10
печать(сложить(3, 4))  # 7
```

## Классы и объекты

### Классы

```trest
класс Человек {
    функция конструктор(имя, возраст) {
        это.имя = имя
        это.возраст = возраст
    }
    
    функция представиться() {
        печать("Меня зовут " + это.имя + ", мне " + это.возраст + " лет")
    }
}

пусть иван = новый Человек("Иван", 30)
иван.представиться()  # "Меня зовут Иван, мне 30 лет"
```

### Наследование

```trest
класс Студент расширяет Человек {
    функция конструктор(имя, возраст, группа) {
        супер(имя, возраст)
        это.группа = группа
    }
    
    функция учиться() {
        печать(это.имя + " учится в группе " + это.группа)
    }
}

пусть студент = новый Студент("Мария", 20, "ИТ-101")
студент.представиться()  # "Меня зовут Мария, мне 20 лет"
студент.учиться()         # "Мария учится в группе ИТ-101"
```

### Статические методы

```trest
класс Математика {
    статический функция факториал(n) {
        если (n <= 1) {
            вернуть 1
        }
        вернуть n * Математика.факториал(n - 1)
    }
}

печать(Математика.факториал(5))  # 120
```

# math.trest
экспорт функция сложить(a, b) {
    вернуть a + b

### Импорт

```trest
# main.trest
импорт { сложить, умножить } из "./math.trest"

печать(сложить(5, 3))  # 8
печать(умножить(2, 4)) # 8

# Импорт всего модуля
импорт * как Math из "./math.trest"
печать(Math.сложить(10, 20))  # 30
```

## Обработка ошибок

### try/catch/finally

```trest
попытаться {
    пусть результат = 10 / 0
    печать(результат)
} перехватить (ошибка) {
    печать("Ошибка: " + ошибка)
} наконец {
    печать("Операция завершена")
}
```

### throw

```trest
функция делить(a, b) {
    если (b == 0) {
        бросить "Деление на ноль!"
    }
    вернуть a / b
}

попытаться {
    делить(10, 0)
} перехватить (ошибка) {
    печать("Ошибка: " + ошибка)
}
```

## Расширенные возможности

### Деструктуризация

```trest
# Массивы
пусть [a, b, c] = [1, 2, 3]
печать(a)  # 1

# Объекты
пусть { имя, возраст } = { имя: "Иван", возраст: 30 }
печать(имя)  # "Иван"
```

### Spread оператор

```trest
# Массивы
пусть arr1 = [1, 2, 3]
пусть arr2 = [4, 5, 6]
пусть объединенный = [...arr1, ...arr2]  # [1, 2, 3, 4, 5, 6]

# Объекты
пусть obj1 = { a: 1, b: 2 }
пусть obj2 = { ...obj1, c: 3 }  # { a: 1, b: 2, c: 3 }
```

### Генераторы

```trest
функция* числа() {
    пусть i = 0
    пока (истина) {
        дать i
        i = i + 1
    }
}

пусть генератор = числа()
печать(генератор.следующий())  # 0
печать(генератор.следующий())  # 1
```
